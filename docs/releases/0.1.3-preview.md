# Petologic 0.1.3 preview — Português, English e Markdown

Android 12+ · ARM64 · APK 97.6 MB. O modelo LFM2.5-350M descarrega separadamente (229 MB).

- Interface PT/EN para Chat, menus, permissões, modelos, widget e Sprite; escolha de idioma por app no Android 13+.
- Respostas com títulos, listas, código, tabelas e tarefas. Sem carregamento automático de imagens nem execução HTML.
- Bolha com deslocamento vertical e botões empilhados quando a letra está ampliada.
- Instalação e atualização documentadas em português.

## Instalar

1. Descarrega `petologic-0.1.3-preview-arm64.apk` nos ficheiros desta versão e abre-o no Android.
2. Se pedido, permite instalar apps a partir do browser/gestor de ficheiros e confirma. Não desatives o Play Protect.
3. Se já tens uma versão pública assinada, instala por cima sem desinstalar. A atualização 0.1.2 → 0.1.3 manteve uma sessão no emulador. Builds debug têm outra assinatura.
4. Abre Definições, instala/importa LFM2.5-350M Q4_K_M, espera pela verificação e conversa em Tiny.
5. Em Definições → Sprite e widget, ativa o Sprite flutuante e autoriza Apresentar sobre outras apps. Toca para conversar; arrasta para mover. Nova conversa e Conversa completa partilham as sessões da app.
6. No Android 13+, muda o idioma em Definições → Idioma. No Android 12, segue o idioma do telemóvel.

O ficheiro INSTALL-ANDROID.md contém o guia completo. Maxx com chave API é opcional; OAuth ainda não está ligado.

## Verificação e limites

36 testes JVM, lint e builds passaram. 8 testes Android finais passaram, incluindo as mesmas cinco perguntas com modelo real na app/bolha; português testado com letra normal e a 200%. Ainda faltam validação física/TalkBack, bateria e testes cloud com conta real. O modelo pequeno pode precisar de reparação limitada para chamar ferramentas; não está certificado para tarefas gerais.
