# Petologic 0.1.2 preview — Chat and Sprite visual update

Android 12+ / ARM64. Download the APK below and open it on your phone. Existing signed 0.1.1 previews can update in place with the same signing identity. Developer debug builds still have a different signature.

- Unified navy/gold theme across Chat, settings, menus and the floating Sprite.
- More room for messages, smaller welcome illustration, selectable text and a new-conversation header action.
- Clearer FAB actions, Full chat and contextual Open to approve; opening from the Sprite returns to the active Chat session.
- Compact bubble previews simplify paired bold/code emphasis; original messages remain intact.

36 JVM tests, lint, builds and 9 Android instrumented tests passed, including the same five real local-model questions in Chat and Sprite, drag/position restoration and navigation. Physical-phone accessibility/battery, full PT/EN interface translation, richer Markdown and supplied sprite background cleanup remain pending. OpenAI/Z.ai API keys are implemented; OAuth and live provider validation remain pending.

LFM2.5-350M downloads separately during setup (229 MB). Floating Sprite requires display-over-other-apps permission and can be stopped from its notification/settings. No new permissions were added for this visual update.
