# Petologic 0.1.1 preview

Native Android preview with 0xPaladino, local Tiny chat, sessions, notes and an opt-in animated floating Sprite. Android 12+ (API 31), ARM64 phones only.

## Install

1. Download `petologic-0.1.1-preview-arm64.apk` and open it on your phone.
2. If Android asks, allow this browser/file manager to install this APK. Review the installer and confirm installation.
3. In Settings, set up the mandatory LFM2.5-350M local model (229 MB download, not embedded in the APK).
4. Enable the floating Sprite in Settings and grant Android's display-over-other-apps permission. Use its notification/stop control to stop it.

`SHA256SUMS.txt` contains the signed APK checksum. APK: 97,256,820 bytes. Signing certificate SHA-256: `bbb593b41123f3239be46ac4260c352f60f8a4179e3f1a8b596f39516763f4c7`.

## Verified

35 JVM tests, Android lint and builds passed. Five identical prompts through Chat and the floating Sprite passed with the actual local model: PT/EN greetings, summary, approved note saving followed by prose, and actual note search followed by prose. Four focused instrumentation tests passed. This signed release installed and opened successfully on a clean Android API 35 ARM64 emulator.

## Preview limits

OpenRouter, OpenAI and Z.ai API key settings are implemented; live provider inference still needs validation with an account. Browser OAuth is not connected yet. Maxx currently returns text only; local note tools run in Tiny. Physical-device battery/lifecycle, signed-version upgrades and broad language/model evaluation remain to be tested. Some supplied sprite frames still have visible background artifacts. Overlay cannot appear over protected Android surfaces.

A developer debug APK uses a different certificate and cannot be updated in place with this signed APK. Do not uninstall an existing build without preserving important data. Future signed previews will retain this signing identity.

This repository distributes APKs only. Application source is maintained separately.

## Distribution and build record

Public asset: https://github.com/Eboxclaw/petologic-downloads/releases/download/v0.1.1-preview/petologic-0.1.1-preview-arm64.apk

SHA-256: `4e3e652468bb762bfa832b8f05dbc7f6d7731eba6522c0f6dfa706304c53ae65`

Built with Java 17 and `android/gradlew -p android :app:assembleRelease -PpaladinoAbi=arm64-v8a`. The release variant uses application ID `ai.petologic.paladino`, version code 2. Debug defaults retain ARM64 and x86_64 for development.

Aligned using SDK build-tools 36.0.0 `zipalign -f -P 16 4`, then signed with `apksigner sign --ks <keystore> --ks-key-alias paladino --ks-pass file:<password-file> <aligned.apk>`. Verify using `apksigner verify --verbose --print-certs` before computing the checksum. Alignment is not a claim that all native libraries have been certified on 16 KB Android devices.

The signing identity is stored outside git in `~/.local/share/petologic/signing/paladino.jks`, with a separate local password file. Preserve and back up both securely before further releases: losing this key prevents seamless updates. Never commit signing material, API credentials or model weights. Do not regenerate the key for later versions.

Release smoke: clean emulator `Paladino_Release_API35`, installed successfully, cold launch status OK, Chat/onboarding visible, no crash-buffer entries. This is separate from model inference tests on the debug variant. Signed-version upgrade/data-preservation testing remains open.
